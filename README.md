# WontJump.github.io

Personal research blog and CV, built with Jekyll and deployed to GitHub Pages.

## Run locally

```sh
bundle install
bundle exec jekyll serve
```

Open <http://127.0.0.1:4000>. Posts live in `_posts`; pages are Markdown files at the repository root. LaTeX is enabled by default for posts using `\(...\)` inline and `\[...\]` for display maths.

## Personalise

Update the site metadata in `_config.yml`, then replace the provisional education and research details in `cv.md` and `research.md`.
